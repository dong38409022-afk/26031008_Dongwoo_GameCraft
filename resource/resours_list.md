# 리소스 목록
AI를 활용하여 직접 만든 이미지입니다.

| 폴더 | 내용 |
| --- | --- |
| screens | 시작 화면, 종료 화면 |
| backgrounds | 경기장 배경 |
| characters | 플레이어, 적 |
| effects | 대시 잔상, 적 등장 경고 |
| effects/kill | 처치 효과 9장 |
| effects/attack | 베기 효과 7장 (현재 미사용) |
| ui | 체력 하트 |
| ui/stamina | 스태미나 이미지 11장 (현재 미사용) |

이미지 35개를 보존하고 종류별로 정리했습니다.
코드의 LoadImage 경로는 resource 폴더 기준입니다.
빌드·게시하면 하위 폴더 구조 그대로 실행 폴더에 복사됩니다.
