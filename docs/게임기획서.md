# 대시 베기 아레나 게임 기획서

## 1. 게임 소개

| 항목 | 내용 |
| --- | --- |
| 제목 | 대시 베기 아레나 |
| 장르 | 탑다운 생존 액션 |
| 플레이 시간 | 한 판 최대 60초 |

다가오는 적을 피하고 대시로 처치하며 60초 동안 살아남는 게임이다. 대시는 이동 수단이자 유일한 공격 수단이다. 적을 모아 한 번에 처치하고, 대시가 다시 준비되는 동안 빈 공간으로 이동하는 것이 핵심이다.

## 2. 경기장과 화면 구성

경기장은 화면 안에 전부 보이는 직사각형 공간이며 내부 장애물은 없다.

| 위치 | 표시 내용 |
| --- | --- |
| 화면 중앙 | 경기장, 플레이어, 적, 전투 효과 |
| 왼쪽 상단 | 남은 체력 |
| 가운데 상단 | 남은 생존 시간 |
| 오른쪽 상단 | 현재 점수 |
| 화면 하단 | 대시 준비 게이지와 조작 안내 |

배경은 어두운 회색, 플레이어는 청록색, 적은 붉은색을 사용한다. 플레이어가 바라보는 방향을 쉽게 알아볼 수 있도록 표현하고, 적과 플레이어는 색상과 형태로 구분한다.

## 3. 이동과 대시

| 키 | 동작 |
| --- | --- |
| WASD 또는 방향키 | 이동 |
| Space | 바라보는 방향으로 대시 |

상하좌우와 대각선으로 이동할 수 있으며, 이동 속도는 방향에 관계없이 같다. 경기장 밖으로는 나갈 수 없다.

대시 방향은 이동 중인 방향을 따르고, 멈춰 있으면 마지막 이동 방향을 사용한다. 시작 시에는 오른쪽을 바라본다. 대시를 시작하면 끝날 때까지 방향을 바꿀 수 없다.

대시 경로에 닿은 적은 모두 처치한다. 대시 중에는 피해를 받지 않으며, 벽에 닿으면 대시가 끝난다. Space를 누른 채로 있어도 대시는 자동 반복되지 않으며, 다시 사용하려면 키를 놓았다가 눌러야 한다.

| 항목 | 초기 설정 |
| --- | --- |
| 대시 지속 시간 | 0.15초 |
| 대시 속도 | 일반 이동 속도의 4배 |
| 재사용 대기시간 | 대시 종료 후 1초 |
| 공격력 | 적을 한 번에 처치 |

재사용 대기시간에는 이동만 가능하다. 대시 게이지가 가득 차면 밝은 색과 `대시 준비` 문구로 알린다.

## 4. 적과 난이도

적은 플레이어를 따라오는 추적형 한 종류다. 플레이어보다 느리게 이동하며 접촉하면 피해를 준다.

적은 경기장 안쪽 가장자리의 무작위 위치에서 나타나되 플레이어와 너무 가까운 곳은 피한다. 등장 전 0.5초 동안 해당 위치에 붉은 경고 표시가 나타난다.

| 경과 시간 | 등장 간격 |
| --- | --- |
| 0~20초 미만 | 1초마다 1마리 |
| 20~40초 미만 | 0.7초마다 1마리 |
| 40~60초 | 0.4초마다 1마리 |

적과 등장 대기 중인 적의 합계는 최대 40마리다. 제한에 도달하면 추가 등장을 멈추고 수가 줄면 다시 등장한다.

## 5. 체력과 점수

시작 체력은 3이다. 대시 중이 아닐 때 적과 닿으면 체력이 1 감소하고, 이후 1초 동안 무적 상태가 된다. 무적 상태에서는 플레이어가 깜빡인다. 여러 적과 동시에 접촉해도 한 번에 체력이 1만 감소하며 접촉한 적은 사라지지 않는다.

- 체력이 0이면 게임 오버다.
- 체력이 남은 상태로 60초를 버티면 클리어다.
- 체력이 0이 되는 순간 60초에 도달해도 게임 오버다.
- 적 한 마리를 처치하면 100점을 얻는다.
- 클리어하면 남은 체력 1당 500점을 추가한다.
- 게임 오버에는 클리어 보너스를 지급하지 않는다.

```text
최종 점수 = 처치한 적 수 × 100 + 클리어 보너스
```

## 6. 필요한 시각 리소스와 연출

| 리소스 | 내용 | 수량 |
| --- | --- | --- |
| 플레이어 | 청록색 캐릭터, 바라보는 방향 구분 | 1종 |
| 기본 적 | 붉은색 추적형 적 | 1종 |
| 경기장 배경 | 어두운 배경과 밝은 테두리 | 1개 |
| 대시 잔상 | 플레이어가 지나간 자리에 잠깐 남는 흔적 | 1종 |
| 베기 효과 | 대시 방향으로 나타나는 짧고 밝은 선 | 1종 |
| 처치 효과 | 적 위치에서 퍼졌다 사라지는 붉은 파편 | 1종 |
| 등장 경고 | 적이 나타날 위치를 알려 주는 붉은 표시 | 1종 |
| 상태 표시 | 체력, 시간, 점수, 대시 게이지 | 1세트 |
| 타이틀 화면 | 게임 제목과 조작 안내 | 1개 |
| 결과 화면 | 클리어·게임 오버, 점수와 플레이 결과 | 1세트 |

플레이어와 적의 모습은 단순하고 알아보기 쉽게 구성한다. 대시와 처치 효과는 짧게 보여 주어 전투 상황을 가리지 않도록 한다. 타이틀이나 캐릭터에 사용할 추가 이미지는 선택 사항이다.

## 7. 필요한 사운드

| 사운드 | 느낌과 용도 | 수량 | 범위 |
| --- | --- | --- | --- |
| 대시 효과음 | 짧은 바람 소리, 대시 시작 알림 | 1개 | 기본 |
| 적 처치 효과음 | 짧고 날카로운 베기 소리, 명중 확인 | 1개 | 기본 |
| 피격 효과음 | 낮고 둔탁한 소리, 체력 감소 알림 | 1개 | 기본 |
| 클리어 효과음 | 짧고 밝은 성공음 | 1개 | 선택 |
| 게임 오버 효과음 | 낮아지는 실패음 | 1개 | 선택 |
| 전투 배경음악 | 빠른 박자의 가사 없는 반복 음악 | 1곡 | 선택 |

한 번에 여러 적을 처치해도 처치음이 과하게 겹치지 않도록 한다. 피격음은 전투 중에도 명확하게 들려야 한다. 외부 이미지와 음원은 사용 가능한 리소스를 준비하고 출처를 기록한다.

## 8. 진행 흐름과 제작 범위

```text
타이틀 및 조작 안내 → Enter로 시작 → 60초 생존 도전 → 결과
                                                     ↓
                                              재시작 / 타이틀
```

결과 화면에는 클리어 또는 게임 오버 여부, 최종 점수, 클리어 보너스, 처치 수, 생존 시간을 표시한다. `R`로 재시작하고 `Enter`로 타이틀로 돌아간다. 재시작하면 처음 상태에서 새 게임을 시작한다.

첫 완성본의 범위는 경기장 1개, 적 1종, 대시 공격 1개, 60초 생존 모드와 기본 시각 연출·효과음이다. 추가 이미지, 결과 효과음, 배경음악은 선택 사항이다.
